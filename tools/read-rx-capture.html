UV-K6 D4 receive capture reader

Reads diagnostic capture bytes from D4 firmware (D2/D3 also supported) through your existing two-pin programming cable. It sends no EEPROM-write, firmware-update, tuning or transmit commands. Data stays in this browser until you save it.

  1. Boot the radio normally with D4 installed. Enable APRS, use MAIN ONLY and your active FM beacon channel.
  2. Press F then 5, then press 2 to select profile B:REF (TA1JS filter and gain settings). Press 1 to clear/unfreeze captures. Send a beacon and wait three seconds.
  3. Close CHIRP and the firmware updater so they release the COM port.
  4. Click Connect, select your programming cable, then Read captures and Save JSON. Send that JSON file back in the chat.

To collect another beacon after reading, press 1 on the radio again. Reading freezes the stored captures; the live receive counters continue.

Use Chrome or Edge. Open this downloaded HTML file locally. No installation or internet connection is needed.
