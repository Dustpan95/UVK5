A custom interface for the UV-K6.

Compare the home-screen layouts, then try the proposed radio and APRS navigation. Each display uses the radio’s actual 128 × 64 pixels and existing bitmap fonts. The selected direction combines a prominent channel name in memory mode with a large frequency in VFO mode, a smaller secondary VFO, battery percentage and brief APRS banners. The APRS screen layouts have been accepted; details remain under review. These are concepts, not implemented firmware behavior.

Try the proposed controls

Keyboard: arrows, Enter, Escape, A for APRS, and Space held for PTT. The mockup simulates navigation only. Tune steps are illustrative; transmitter actions send nothing.

Compare the behavior

Brief banners are selected. The automatic-open alternative remains available for comparison. Sound defaults ON and follows global beep OFF. Banner duration and dismissal behavior are still open. Battery percentage is shown on every screen; 76% is example data.

Still open for design reviewBanner timing, shortcuts, session-history capacity, multi-tap key details, and message ACK/retry behavior. No final feature cuts have been chosen.

Messaging workflow review

Messaging is primary. Multi-tap typing plus saved quick messages is selected. These new screens propose recipient entry, editable quick-message insertion, a review step, and delivery status. Key assignments, timeout/retry policy and capacity remain for review. No control sends RF.

Feature tradeoffs to weigh before cutting

The current provisional receive build uses 61,024 of 61,440 flash bytes. That includes the approved custom home and message alerts. Standard-compatible TX is not yet in the radio build.
